# AP-DIAG-045 — Missed Ground-Truth Splice Analysis

## Status

IMPLEMENTATION CANDIDATE — diagnostic only.

No production extraction logic is modified.

## Objective

Analyze the 9 manually verified TRX300 source splice locations that AP-DIAG-044 proves are currently not represented by the 35 AP-DIAG-042 residual splice population.

This AP does not change splice detection, endpoint promotion, topology, wire reconstruction, or semantic classification.

## Inputs

- Canonical source: `samples/trx300ODG.png`
- AP-DIAG-044 report: `artifacts/audit/AP-DIAG-044_splice_ground_truth.json`
- Current production model: generated by the unmodified `ExtractionPipeline`

## Measurements

For each missed splice, record:

- registered source coordinate
- nearest topology node and distance
- topology-node type
- incident topology-edge degree
- unique conductor-segment count
- repeated conductor-segment incidents
- nearest endpoint candidate and distance
- endpoint kind / terminal role / incident-edge count
- nearby component and connector geometry
- local raster ink density and directional support
- an observational failure signature

The signature describes the current model's observable state. It is not a production classification rule.

## Outputs

- `artifacts/audit/AP-DIAG-045_missed_splice_analysis.json`
- `artifacts/missed_splice_analysis/missed-001.png` … `missed-009.png`
- `artifacts/missed_splice_analysis/AP-DIAG-045_contact_sheet.png`

## Acceptance

Do not use this AP to select a production fix until:

1. exactly 9 missed AP-DIAG-044 records are consumed;
2. all 9 records resolve to source coordinates;
3. all 9 evidence records are emitted;
4. crops and contact sheet are generated;
5. the report distinguishes observation from inference;
6. no production extraction source is modified;
7. clean Release build passes;
8. full CTest passes;
9. the AP acceptance gate passes.

The next production AP must be derived from the measured common failure signature, not from a single missed splice.
